Diseñado para eliminar la incertidumbre del taller.

Sin planillas sueltas ni presupuestos verbales. Cada vehículo, repuesto y hora de mano de obra responde a reglas verificables.

SPEC // 01

Diagnóstico antes de presupuestar

Ninguna orden puede cotizarse sin registro técnico previo del mecánico asignado y desglose exacto de mano de obra.

SPEC // 02

Reserva atómica de inventario

Al asignar un repuesto a una orden, PostgreSQL bloquea la fila y descuenta el stock real. Si se cancela, vuelve al depósito.

SPEC // 03

Precios congelados por orden

El cliente aprueba un presupuesto cerrado: aunque el repuesto cambie de precio mañana, la orden conserva su valor original.

SPEC // 04

Una orden activa por patente

Evita duplicados y superposiciones entre mecánicos normalizando cada patente al ingresar al sistema.
